# JINA — первые накопления для 18–24

Кейс продакт-менеджера: как научить 18–24 копить и не превратить это в казино.
Начинался как решение хакатона BCC Future Talent (кейс «Крипто-необанк»), доработан до цельного продукта.

- **Сайт-кейс:** проблема → аудитория → исследование → решения → экономика → гипотезы → выводы
- **Живой прототип:** `/app.html` — работает в браузере, без регистрации, все данные синтетические

## Что внутри продукта

- Копить от 1 000 ₸ в тенге и граммах золота
- Цена выхода видна до покупки: 10 000 ₸ → 0,1600 г → ≈ 9 800 ₸, если продать сразу
- «Курс обновился»: было / стало, без подтверждения ничего не списывается
- Кешбэк тенге или граммами — две равные карточки без выбора по умолчанию
- «Солнце накоплений» вместо стриков: 32 луча до первого грамма
- Пять коротких уроков с вопросом на понимание (подушка, золото, акции и фонды, крипта)
- Метрики демо: воронка только из событий текущей сессии, с пометкой «не исследование»

## Запуск

```bash
cd prototype
npm install
npm test        # 27 тестов на расчёты: опорные числа, округление, защита от двойного списания
npm run dev     # http://localhost:5173 — сайт, /app.html — прототип
npm run build   # статическая сборка в prototype/dist
```

Стек: React, TypeScript, Tailwind, Vite, Vitest. Шрифты Unbounded и Onest.

Бренд, партнёры, цены и метрики демонстрационные и не являются предложением банка. Результаты опроса реальные.
