## Известные проблемы

- Вкладка «Кешбэк» открывается как вкладка (без кнопки «Назад»), в том числе после успеха покупки.
- E1 по умолчанию «вверх»: первое истечение котировки в демо всегда показывает рост курса; после «Отменить» режим E1 выключается.
- Демо-режим E4 остаётся включённым, пока его не выключить в панели.
- Шрифт системный (сборка работает офлайн). Шрифт из Figma подключить в `tokens.css`.

## Решения, принятые по ходу

- Деньги: ₸ — целые числа, граммы — целые микрограммы; граммы на экране вниз до 0,0001 г, ₸ — от реестра.
- Реестр операций (`src/lib/ledger.ts`) идемпотентен по `operationId`; id покупки привязан к котировке.
- Состояние — `useReducer` + context (`src/store.tsx`), `localStorage` в try/catch.
- Превью для Claude: `.claude/launch.json` → `vite preview` на порту 4173.
