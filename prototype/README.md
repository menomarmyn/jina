# Прототип «JINABACK»

Интерактивный mobile-first прототип для защиты кейса BCC Future Talent. Все данные синтетические.

## Запуск

```bash
npm install
npm test          # расчёты и опорные числа
npm run build     # один файл dist/index.html, открывается без сервера
npm run dev       # разработка
```

## Демо-сценарий (3–4 минуты)

Онбординг → Даурен → пополнение 50 000 ₸ → покупка 10 000 ₸ → «Истечь котировку сейчас» → «Курс обновился» →
«Отменить» → покупка заново → 0,1600 г → кешбэк → Vexelia (демо) → главная 59 960 ₸.

## Демо-панель

Открыть: `?demo=1` в адресе, **Shift+D**, 5 быстрых тапов по верхней середине экрана или по логотипу на главной.

- Сброс к онбордингу / итог сценария Даурена
- E1: курс при истечении — без изменений / вверх / вниз; «Истечь котировку сейчас» (на экране подтверждения)
- E2: не хватает тенге (баланс 10 000, покупка 15 000)
- E3: условный лимит (покупка 60 000 при лимите 50 000)
- E4: ответ «завис» → «Проверяем статус»
- Порядок карточек кешбэка, смена профиля

- `src/styles/tokens.css` — цвета и радиусы; при приходе Figma меняются только значения
